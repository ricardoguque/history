# Historia

Proyecto personal para explorar la historia, desde el origen del universo hasta
la actualidad, mediante una línea de tiempo interactiva y un catálogo de lecturas.

El objetivo es relacionar hitos históricos con libros y fuentes, contrastar fechas
y llevar un registro de lo leído. El sitio será estático, bilingüe (español e
inglés), con datos en YAML y publicación en GitHub Pages.

Incluye un prototipo con Astro y React, temas oscuros y edición de los datos
mediante el editor de GitHub.

Consulta [HLD.md](HLD.md) para conocer la visión
y las decisiones de alto nivel.
